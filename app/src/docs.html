API Documentation

Base URL: https://open-radar.live

GET /api/findings

Returns paginated leaked secrets scraped from GitHub repositories.

Query Parameters

page integer
Page number. Default: 1
page_size integer
Results per page (1-100). Default: 25
provider string
Filter by provider (e.g. openai, anthropic, google). Default: * (all)
min_age string
Time window as Go duration (e.g. 24h, 168h). Default: 24h

Response

{
  "findings": [
    {
      "id": "uuid",
      "scan_job_id": "uuid",
      "repo_name": "https://api.github.com/user/repo",
      "file_path": "src/config.js",
      "detected_at": "2026-02-21T06:00:00Z",
      "key": "sk-abc...xyz",
      "provider": "openai"
    }
  ],
  "page": 1,
  "page_size": 25,
  "total_count": 1842,
  "total_pages": 74
}
GET /api/findings/count

Returns the amount of findings scraped in total.

Response

{
  "total_count": 1842,
}
GET /api/repositories

Returns paginated scraped GitHub repositories.

Query Parameters

page integer
Page number. Default: 1
page_size integer
Results per page (1-100). Default: 25

Response

"repositories": [
    {
      "scan_job_id": "uuid",
      "repo_name": "https://api.github.com/repos/user/",
      "last_updated": "2026-02-21T06:00:00Z"
    }
]
GET /api/repositories/findings

Returns the findings for a specific repository.

Query Parameters

repo_url string
The API url (e.g. https://api.github.com/repos/user/repo_name)

Response

{
  "findings": [
    {
      "id": "uuid",
      "scan_job_id": "uuid",
      "repo_name": "https://api.github.com/repos/user/name",
      "file_path": "src/config.js",
      "detected_at": "2026-02-21T06:00:00Z",
      "key": "string",
      "provider": "string"
    }
  ],
  "page": 1,
  "page_size": 25,
  "total_count": 1,
  "total_pages": 1
}
GET /api/repositories/count

Returns the amount of repositories scraped in total.

Response

{
  "total_count": 56970,
}
